설정 파일 없이 시작하거나 사용자 지정 **webpack.config.js** 파일을 제공하세요.

```js
const path = require("node:path");

module.exports = {
  entry: "./src/index.js",
  output: {
    path: path.resolve(__dirname, "dist"),
    filename: "bundle.js",
  },
};
```
