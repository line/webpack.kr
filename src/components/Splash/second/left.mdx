**webpack.config.js**에서 webpack이 페이지를 가리키도록 설정하세요.

```js
export default {
  entry: "./src/index.html",
  output: {
    // the page loads a `<script type="module">`, so emit ES modules to match
    module: true,
  },
};
```

Webpack은 페이지를 파싱하고 페이지가 참조하는 모든 항목을 번들링한 다음 URL을 다시 작성합니다. loader나 plugin은 필요하지 않습니다.
