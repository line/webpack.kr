`object` `string`

`stats` 옵션을 사용하면 표시되는 번들 정보를 정확하게 제어할 수 있습니다. 번들 정보를 얻고 싶지만 전부에 대한 정보를 얻고자 하는 것은 아닐 것이기 때문에 `quiet` 또는 `noInfo`를 사용하지 않는 경우 좋은 절충안이 될 수 있습니다.

W> 이 옵션은 [Node.js API](/api/node)를 사용할 경우에는 아무 효과가 없습니다. stats 옵션을 `stats.toString()`에 전달해야 합니다. 대신 `stats.toJson()`이 호출됩니다.

```js
export default {
  // ...
  stats: "errors-only",
};
```

## Stats Presets

Webpack은 stats 출력에 사용할 수있는 특정 프리셋을 함께 제공합니다.

| Preset              | Alternative | Description                                                                                                                                                                                                                                                    |
| ------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `'errors-only'`     | _none_      | 에러가 발생할 때만 출력                                                                                                                                                                                                                                        |
| `'errors-warnings'` | _none_      | 에러와 경고가 발생할 때만 출력                                                                                                                                                                                                                                 |
| `'minimal'`         | _none_      | 에러와 새로운 컴파일이 발생할 때만 출력                                                                                                                                                                                                                        |
| `'none'`            | `false`     | 출력 없음                                                                                                                                                                                                                                                      |
| `'normal'`          | `true`      | 표준 출력                                                                                                                                                                                                                                                      |
| `'verbose'`         | _none_      | 모두 출력                                                                                                                                                                                                                                                      |
| `'detailed'`        | _none_      | `'verbose'`와 유사하지만 `chunkModules`, `chunkGroupResourceHints`, `dependentModules`, `reasons`, `orphanModules`, `errorStack`, `env`, `children` 없이, `errorsSpace`, `warningsSpace`, `modulesSpace`, `assetsSpace`, `reasonsSpace`가 1000으로 제한됩니다. |
| `'summary'`         | _none_      | webpack 버전, 경고 횟수, 에러 횟수를 출력                                                                                                                                                                                                                      |

## Stats Options

stats 출력에서 보고 싶은 정보를 설정할 수 있습니다.

T> stats 설정 객체의 모든 옵션은 선택 사항입니다.

T> 아래의 기본값은 문자열 출력(`stats.toString()`, CLI에서 사용)을 설명합니다. 이 옵션들은 문자열 출력에서는 `false`이지만 `stats.toJson()`에서는 `true`입니다. `builtAt`, `cachedAssets`, `cachedModules`, `children`, `chunkGroupAuxiliary`, `chunkGroupChildren`, `chunkGroupResourceHints`, `chunkGroups`, `chunkOrigins`, `chunkRelations`, `chunks`, `dependentModules`, `depth`, `errorStack`, `hash`, `ids`, `loggingTrace`, `moduleAssets`, `nestedModules`, `optimizationBailout`, `orphanModules`, `outputPath`, `providedExports`, `publicPath`, `reasons`, `relatedAssets`, `runtimeModules`, `usedExports`.

### stats.all

정의되지 않은 경우 stats 옵션의 폴백입니다. 로컬 webpack의 기본값보다 우선시 됩니다.

```js
export default {
  // ...
  stats: {
    all: undefined,
  },
};
```

### stats.assets

`boolean = true`

애셋 정보 표시 여부를 `stats`에 알려줍니다. 이 정보를 숨기려면 `stats.assets`을 `false`로 설정하세요.

```js
export default {
  // ...
  stats: {
    assets: false,
  },
};
```

### stats.assetsSort

`string = '!size'` `false`

주어진 필드를 기준으로 애셋을 정렬하도록 `stats`에 지시합니다. 모든 [정렬 필드](#sorting-fields)는 `stats.assetsSort`의 값으로 사용할 수 있습니다. 값에 `!`접두사를 사용하여 주어진 필드의 정렬 순서를 반대로 할 수 있습니다. `false`로 설정하면 정렬을 비활성화합니다.

```js
export default {
  // ...
  stats: {
    assetsSort: "!size",
  },
};
```

### stats.chunkGroupResourceHints

`boolean = false`

각 엔트리포인트의 해석된 resource-hint 설명자를 `entrypoints[name].resourceHints`로 포함합니다. [`output.resourceHints.chunks`](/configuration/output/#outputresourcehints)(초기 그래프에 대한 `modulepreload` / `preload` / `prefetch` 힌트)와 `output.resourceHints.assets`(폰트, 이미지 및 기타 URL 참조 애셋)를 결합합니다.

이를 통해 서버 사이드 렌더러가 청크 그래프를 순회하는 대신 `<link>` 태그를 직접 출력할 수 있습니다. `stats.toString()`에서는 `false`이고 `stats.toJson()`에서는 `true`입니다.

```js

    chunkGroupResourceHints: true,
  },
};
```

### stats.context

`string`

stats 기본 디렉터리이며, 요청 정보를 단축하기 위한 **절대경로** 입니다.

```js
import path from "node:path";
import { fileURLToPath } from "node:url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

export default {
  // ...
  stats: {
    context: path.resolve(__dirname, "src/components"),
  },
};
```

기본적으로 [`context`](/configuration/entry-context/#context) 또는 Node.js의 현재 작업 디텍터리 값이 사용됩니다.

### stats.exclude

W> Deprecated 및 비효과: `stats.exclude`는 설정 스키마에서 여전히 허용되지만 읽히지 않습니다. 대신 [`stats.excludeModules`](#statsexcludemodules)를 사용하세요.

### stats.excludeAssets

`(string | RegExp | ((name: string, asset: StatsAsset) => boolean))[] = []` `string` `RegExp` `(name: string, asset: StatsAsset) => boolean`

매칭되는 애셋 정보를 제외하도록 `stats`에 지시합니다. `string`, `RegExp`, 또는 애셋의 이름과 stats 객체를 받는 함수를 사용할 수 있습니다. `stats.excludeAssets`는 위의 항목들 중 하나로 구성된 `array`가 될 수 있습니다.

```js
export default {
  // ...
  stats: {
    excludeAssets: [
      "filter",
      /filter/,
      (assetName) => assetName.contains("moduleA"),
    ],
  },
};
```

### stats.excludeModules

`(string | RegExp | ModuleFilterFn)[] = []` `string` `RegExp` `ModuleFilterFn` `false`

매칭되는 모듈 정보를 제외하도록 `stats`에 지시합니다. `string`, `RegExp`, 또는 `ModuleFilterFn`을 사용할 수 있습니다. `stats.excludeModules`는 위의 항목들 중 하나로 구성된 `array`가 될 수 있습니다.

```ts
type ModuleFilterFn = (
  name: string,
  module: StatsModule,
  type: "module" | "chunk" | "root-of-chunk" | "nested",
) => boolean;
```

```js
export default {
  // ...
  stats: {
    excludeModules: ["filter", /filter/, (moduleName) => true],
  },
};
```

`stats.excludeModules`을 `false`로 설정하면 제외 동작이 비활성화됩니다.

```js
export default {
  // ...
  stats: {
    excludeModules: false,
  },
};
```

### Sorting fields

`assetsSort`, `chunksSort` 및 `modulesSort`의 경우 항목을 정렬할 수 있는 몇 가지 필드가 있습니다.

- `'id'` - the item's id,
- `'depth'` - the module's depth in the module graph (the default for `modulesSort`),
- `'name'` - the item's name that was assigned to it upon importing,
- `'size'` - the size of item in bytes,
- `'chunks'` - what chunks the item originates from (for example, if there are multiple subchunks for one chunk: the subchunks will be grouped according to their main chunk),
- `'errors'` - number of errors in items,
- `'warnings'` - number of warnings in items,
- `'failed'` - whether the item has failed compilation,
- `'cacheable'` - whether the item is cacheable,
- `'built'` - whether the asset has been built,
- `'optional'` - whether the asset is optional.
- `'identifier'` - identifier of the item.
- `'index'` - item's processing index.
- `'index2'`
- `'profile'`
- `'issuer'` - issuer의 식별자
- `'issuerId'` - issuer의 id
- `'issuerName'` - issuer의 이름
- `'issuerPath'` - 전체 issuer 객체. 이 필드를 기준으로 정렬 할 필요는 없습니다.

### Extending stats behaviours

`'minimal'`같은 사전 설정 중 하나를 사용하지만 일부 규칙을 재정의하는 경우, 원하는 `stats.preset`을 지정하고 사용자 지정 또는 추가 규칙을 추가하면 됩니다.

**webpack.config.js**

```js
export default {
  // ..
  stats: {
    preset: "minimal",
    moduleTrace: true,
    errorDetails: true,
  },
};
```
