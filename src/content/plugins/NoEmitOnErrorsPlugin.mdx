`NoEmitOnErrorsPlugin`을 사용하면 오류가 있을 때 애셋 방출을 피할 수 있습니다. `production` 모드에서는 기본적으로 활성화되어 있으며, [`optimization.emitOnErrors`](/configuration/optimization/#optimizationemitonerrors)의 기본값이 `false`입니다. 해당 옵션을 사용하여 활성화하거나 비활성화할 수 있습니다.

**webpack.config.js**

```js
export default {
  plugins: [new webpack.NoEmitOnErrorsPlugin()],
};
```
