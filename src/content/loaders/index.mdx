## What needs no loader

Webpack은 다음 항목을 자체적으로 처리합니다. 이 목록에 _없는_ 항목에만 loader를 설치하세요.

- **JavaScript**, ESM and CommonJS
- **JSON**
- **이미지, 폰트, 미디어, 텍스트 파일** — `file-loader`, `url-loader`, `raw-loader`를 대체하는 [Asset Modules](/guides/asset-modules/)
- **WebAssembly** — [`experiments.asyncWebAssembly`](/configuration/experiments/#experiments)
- **CSS** — 실험적인 [`experiments.css`](/configuration/experiments/#experimentscss). [지원 범위](/guides/native-css/#whats-built-in) 참고
- **HTML** — 실험적인 [`experiments.html`](/configuration/experiments/#experimentshtml). [지원 범위](/guides/native-html/#whats-built-in) 참고
- **TypeScript** — 실험적인 [`experiments.typescript`](/configuration/experiments/#experimentstypescript). Node.js 22.6 이상에서 타입을 제거하지만 타입 검사나 JSX 처리는 하지 않음

Webpack은 그 밖의 항목을 전처리할 수 있도록 [loader](/concepts/loaders)를 지원합니다. 이를 통해 JavaScript 외의 모든 정적 리소스를 번들링할 수 있으며 Node.js로 자체 loader를 쉽게 작성할 수 있습니다.
Loader는 webpack 기능을 확장하는 별도 패키지이며 더 넓은 생태계에서 관리됩니다.
`import .. from "mod";`/`require()` 문에 `loadername!` 접두사를 사용하거나 webpack 설정의 정규식을 통해 loader를 자동 적용할 수 있습니다. [설정](/concepts/loaders/#configuration)을 참고하세요.

## Files

- [`ref-loader`](https://www.npmjs.com/package/ref-loader)는 수동으로 파일 간의 의존성을 생성합니다.

## JSON

- [`cson-loader`](https://github.com/awnist/cson-loader)는 [CSON](https://github.com/bevry/cson#what-is-cson) 파일을 로드 및 트랜스파일 합니다.

## Transpiling

- [`babel-loader`](/loaders/babel-loader)는 ES2015+ 코드를 로드하고 [Babel](https://babeljs.io/)을 사용해 ES5로 트랜스파일 합니다.
- [`esbuild-loader`](https://github.com/privatenumber/esbuild-loader)를 사용하여 ES2015+ 코드를 로드하고, [esbuild](https://esbuild.github.io/)를 통해 ES6+ 코드로 변환합니다.
- [`buble-loader`](https://github.com/sairion/buble-loader)는 ES2015+ 코드를 로드하고 [Bublé](https://buble.surge.sh/guide/)를 사용해 ES5로 트랜스파일 합니다.
- [`traceur-loader`](https://github.com/jupl/traceur-loader)는 ES2015+ 코드를 로드하고 [Traceur](https://github.com/google/traceur-compiler#readme)를 사용해 ES5로 트랜스파일 합니다.
- [`ts-loader`](https://github.com/TypeStrong/ts-loader)는 JavaScript처럼 [TypeScript](https://www.typescriptlang.org/) 2.0+를 로드합니다.
- [`coffee-loader`](/loaders/coffee-loader)는 JavaScript처럼 [CoffeeScript](http://coffeescript.org/)를 로드합니다.
- [`fengari-loader`](https://github.com/fengari-lua/fengari-loader/)는 [fengari](https://fengari.io/)를 사용해 Lua 코드를 로드합니다.
- [`elm-webpack-loader`](https://github.com/elm-community/elm-webpack-loader)는 JavaScript처럼 [Elm](https://elm-lang.org/)을 로드합니다.

## Templating

T> HTML은 실험적인 [`experiments.html`](/configuration/experiments/#experimentshtml)로 내장 지원하므로 일반 HTML에 대한 로더는 이 목록에 포함하지 않습니다. [Native HTML](/guides/native-html/) 가이드에서 [내장 기능](/guides/native-html/#whats-built-in)과 기존 설정을 이전하는 방법을 설명합니다. template engine에는 항상 해당 로더가 필요합니다.

- [`pug-loader`](https://github.com/pugjs/pug-loader)는 Pug 및 Jade template을 로드하고 함수를 반환합니다.
- [`markdown-loader`](https://github.com/peerigon/markdown-loader)는 Markdown을 HTML로 컴파일합니다.
- [`react-markdown-loader`](https://github.com/javiercf/react-markdown-loader)는 markdown-parse parser를 사용해 Markdown을 React Component로 컴파일합니다.
- [`posthtml-loader`](https://github.com/posthtml/posthtml-loader)는 [PostHTML](https://github.com/posthtml/posthtml)을 사용해 HTML 파일을 로드하고 변환합니다.
- [`handlebars-loader`](https://github.com/pcardune/handlebars-loader)는 Handlebars를 HTML로 컴파일합니다.
- [`markup-inline-loader`](https://github.com/asnowwolf/markup-inline-loader)는 SVG/MathML 파일을 HTML에 인라인으로 삽입합니다. icon font 또는 SVG에 CSS animation을 적용할 때 유용합니다.
- [`twig-loader`](https://github.com/zimmo-be/twig-loader)는 Twig template을 컴파일하고 함수를 반환합니다.

## Styling

T> CSS는 실험적인 [`experiments.css`](/configuration/experiments/#experimentscss)로 내장 지원하므로 [`css-loader`](/loaders/css-loader)와 [`style-loader`](/loaders/style-loader)를 이 목록에 포함하지 않습니다. 내장 대안이 없는 옵션을 위해 두 문서는 유지됩니다. [What's built-in](/guides/native-css/#whats-built-in)을 참고하세요. preprocessor에는 항상 해당 loader가 필요합니다.

- [`css-utility-loader`](https://github.com/SahilKhanWDC/css-utility-loader-webpack-.git)는 빌드 시점에 legacy CSS property를 파싱하여 최신 utility class(Tailwind)로 변환합니다.
- [`less-loader`](/loaders/less-loader)는 LESS 파일을 로드하고 컴파일합니다.
- [`sass-loader`](/loaders/sass-loader)는 SASS/SCSS 파일을 로드하고 컴파일합니다.
- [`postcss-loader`](/loaders/postcss-loader)는 [PostCSS](http://postcss.org)를 사용해 CSS/SSS 파일을 로드하고 변환합니다.
- [`stylus-loader`](/loaders/stylus-loader/)는 Stylus 파일을 로드하고 컴파일합니다.

## Frameworks

- [`vue-loader`](https://github.com/vuejs/vue-loader)는 [Vue Components](https://vuejs.org/v2/guide/components.html)를 로드하고 컴파일합니다.
- [`angular2-template-loader`](https://github.com/TheLarkInn/angular2-template-loader)는 [Angular](https://angular.io/) 컴포넌트를 로드하고 컴파일합니다.
